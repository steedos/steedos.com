## 场景说明  

许多企业希望通过华炎魔方实现匿名表单收集（如用户反馈、活动报名等），但原生方案需要通过代码来开发实现，对非技术用户门槛较高。

本教程提供一种零代码解决方案：通过飞书多维表格作为前端表单，用户提交数据后，利用飞书自动化规则将数据实时同步至华炎魔方对象表。

无需开发，仅需简单配置即可完成匿名数据收集与自动同步，适合市场、运营等非技术人员快速落地需求，同时保留华炎魔方的数据管理能力。

## 在华炎魔方中创建业务对象

### 创建“开源共创计划”对象

在对象列表处，点击“新建对象”，将对象命名为“开源共创计划”（opensource_planning），并填写对象的描述信息，便于后续维护与识别。

### 添加对象字段

为对象添加所需的字段，例如：

- 公司名称（文本类型）
- 联系人（文本类型）
- 联系电话（文本类型）
- 职位（单选或多选类型）
- 咨询时间（日期时间类型）
- ......

每个字段都可在华炎魔方中灵活设置数据格式、权限与校验规则，以确保数据质量与安全性。

![](/images/cms/681b1d2b5c7a28060df69665.webp)

### 配置权限与可见性

确保对象只对需要的角色或用户组开放相应操作权限。这样既能方便后续的管理，又能保证系统数据的安全与合规。

![](/images/cms/681b405d5c7a28060df6966d.webp)

### 进入华炎魔方应用构建界面

在华炎魔方平台的管理后台，选择您所使用的应用或创建一个新的业务应用。进入应用构建页面后，即可开始定义所需的数据实体对象选项卡。

![](/images/cms/681b40ec5c7a28060df6966f.webp)

设置完成后，有权限的用户就可以在前台访问我们设置的业务应用了。

## 在飞书多维表格中创建咨询表单并生成匿名填写页面

### 创建飞书多维表格

登录飞书，进入多维表格功能，点击“新建表格”，命名为“开源共创计划”。多维表格具备丰富的结构化数据编辑能力，您可以依据业务归类对列进行命名，例如“公司名称”、“联系人”、“职位”等。

![](/images/cms/681b453b5c7a28060df69675.webp)

### 设计字段列

在多维表格的第一行（标题行）分别设置上述列名，并在下方设置示例数据或测试数据，以便后续调试使用。多维表格可以根据列的数据类型进行简单的格式和校验设置，也能进行条件筛选、分组等操作。

### 开启匿名填写功能

为了便于客户直接访问并提交咨询信息，需要开启多维表格的匿名填写功能。进入该表格的“分享”或“设置”选项中，开启“允许匿名访问表格”或“允许通过链接填写”之类的选项，然后生成外部可访问链接。此操作后，您可以将此链接分发给潜在客户，或嵌入企业官网、公众号、H5 页面，让客户能够实时提交咨询信息。

![](/images/cms/681b1cb95c7a28060df69663.webp)

### 测试匿名填写

使用生成的链接，打开浏览器测试填写流程，确保表格页面能够正常访问并提交数据。此步骤将有助于您后续在配置自动化时更快地定位问题。

## 在飞书中配置自动化规则，调用华炎魔方OpenAPI


### 调用华炎魔方OpenAPI 前的准备

确认华炎魔方开放平台（OpenAPI）已启用，并在系统中获取相应的访问令牌（Token）信息。

- 管理员进入后台`设置-API Key`，获取认证Token（如 `apikey,XXXXXX`）

   ![](/images/cms/681b434d5c7a28060df69672.webp)

- 管理员获取写入记录的标准接口地址（如 `example.com/api/v6`）；

   ![](/images/cms/681b1d815c7a28060df69667.webp)
   
### 在飞书多维表格中启用自动化

打开“开源共创计划”表格，在右上角或侧边栏找到自动化配置入口（部分版本称为“机器人”或“自动化”），选择“添加规则”或“定制机器人”，并设置触发条件。当有新行提交时（即客户匿名填写后，表格多出一条新行），自动执行指定服务调用。

![](/images/cms/681b1e165c7a28060df69669.webp)

### 编写自动化脚本

在飞书的自动化编辑器中，需要使用“发送HTTP请求”模块，向华炎魔方发送 POST 请求，将新飞书匿名提交的信息写入华炎魔方对象中。

通常脚本会包含以下关键内容：

- 请求地址：例如 https://<您的华炎魔方域名>/api/v4/objects/opensource_planning

- HTTP 方法：POST

- Header：包含授权信息，如 Authorization 字段携带您的访问令牌

- Body：包含要写入华炎魔方的字段数据，例如：

```json
   {
   "公司名称": "{{公司名称}}",
   "联系人": "{{联系人}}",
   "联系电话": "{{联系电话}}",
   "来源渠道": "飞书表单"
   }
```
   
配置中可直接引用由多维表格自动化变量提供的列数据（字段变量通过点击输入框右侧的 `➕` 图标选择。），使每条新提交的咨询信息对应写入华炎魔方后端。

 ![](/images/cms/681b1e185c7a28060df6966b.webp)
 
### 自动化规则保存与测试

将自动化配置保存后，为了确保功能正常，建议先手动填写一条测试数据到飞书表格中观察执行情况。可在“自动化日志”或“运行记录”界面查看是否成功触发 API 调用，以及返回结果是否正常。

如果出现错误提示，请检查令牌是否有效、URL 地址是否正确、请求体字段与华炎魔方对象字段是否一致等。

## 常见问题

❌ **错误：`net/http: invalid header field value`**  
- 原因：Headers中 `Content-Type` 或 `Authorization` 格式错误。  
- 解决：严格按示例填写，避免手输，直接粘贴JSON内容。  

❌ **错误：数据未同步**  
- 检查飞书自动化是否启用，华炎魔方API是否响应 `200`。  


通过以上配置，飞书多维表格的数据将自动推送至华炎魔方，实现无缝对接！
